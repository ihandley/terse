# Anti-AI tells

Final scrub after density and medium rules. Derived from Wikipedia "Signs of AI
writing" via [blader/humanizer](https://github.com/blader/humanizer). Flag
**clusters** of tells, not isolated ordinary words. No invented facts/names/
dates/citations to sound human. No blog-style "personality" injected into
workplace media.

Em dash ban and filler-adverb cuts: [principles.md](principles.md).

## §1 Cut or rewrite

| Tell | Action |
| --- | --- |
| Significance inflation ("pivotal moment", "testament to", "evolving landscape") | State the concrete fact |
| Superficial `-ing` tack-ons ("highlighting…", "showcasing…", "ensuring…") | Delete, or keep only sourced substance |
| Promotional fluff ("vibrant", "seamless", "robust", "nestled", "groundbreaking") | Plain wording |
| Vague attributions ("experts believe", "observers note") | Name a real source or cut |
| AI vocabulary pile-up (delve, tapestry, underscore, leverage, facilitate, utilize) | Ordinary verbs |
| Copula avoidance ("serves as", "boasts", "features") | Prefer "is" / "has" |
| "Not just X, but Y" / tailing negations | State the point once |
| Rule-of-three padding | Use a natural number of items |
| Synonym cycling for the same referent | Repeat the clearest noun |
| False ranges ("from X to Y" spanning unrelated topics) | List directly |
| Bold / emoji / Title Case decoration | Plain prose for the medium |
| Inline-header lists ("**Performance:** it improved") | Prose or real lists per mode |
| Chatbot residue ("I hope this helps!", "Happy to help further") | Remove |
| Sycophancy ("Great question!", "You're absolutely right!") | Answer directly |
| Signposting ("Let's dive in", "Here's what you need to know") | Start with the content |
| Persuasive authority tropes ("At its core", "What really matters") | Ordinary claim |
| Generic upbeat closer ("Exciting times ahead") | End on last concrete fact or ask |
| Manufactured staccato drama (stacked one-liners) | Varied, concrete sentences |
| Aphorism formulas ("X is the Y of Z") | Concrete claim |
| Theatrical fake-candid openers ("Honestly?" as a standalone hook) | Just say the thing |

## §2 Preserve (not tells alone)

Specific hard-to-fake detail; mixed feelings / unresolved tension; varied
sentence length; genuine mid-sentence "honestly" / "look" when carrying the
point; one short emphatic sentence (not a run); polish without §1 clusters.

## §3 No fabrication

Missing a real detail → ask or keep plain. Never swap a vague claim for an
invented specific.
